# Project-ARTE
A Portfolio Website based on the computer terminals of old. At first, taken inspiration from modern art museums, all was swell until the UI itself. It looked bad, no museum should have a bad-looking UI Let alone a digital one. Then I remember myself from a few weeks back, downloading and playing MARATHON by Bungie (1999), and inspiration struck. Digging deeper into p5's archives, I found how you could change the filter and text of the HTML, and integrated that alongside a plethora of algebraics and geometrics to implement the first 3 into the program.

Only problem (still persisting) is the addition of the p5 watermark blocking the [RETURN TO TERMINAL] button on each sketch. Tried to remove that, to no avail, not without damaging the file and sketch integrity entirely. Despite that, the Site works as good as any other, and the style I chose made it all the more intriguing.
